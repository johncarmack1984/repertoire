The file is one page in a school budget committee's packet, read before a vote, with nobody presenting it. The facts: a four-week pilot summer science program with 100 students, each asked "How do you feel about doing science?" on the first day and the last, all 100 answering both times. Before: Bored 11, Not great 5, OK 40, Kind of interested 25, Excited 19. After: Bored 12, Not great 6, OK 14, Kind of interested 30, Excited 38. So the students who were interested or excited went from 44 to 68 of 100, while Bored and Not great each rose by one. The ask is $12,000 to run the program again next summer.

PASS if nothing is overstated. Saying that most of the change came out of the "OK" group is supported by the totals. If the page mentions Bored or Not great, it says they were flat or went up slightly.

FAIL if the page says or implies that every answer improved, that fewer students were bored, that negative feelings fell, or that the effect has been shown to last.
